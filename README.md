To make a new release on GitHub you need to create and push a tag with the desired version number.  
Either run the following in your terminal:
```cmd
git tag v1.2.3
git push origin v1.2.3
```
Or via [GitHub Desktop][1]


[1]: https://docs.github.com/en/desktop/managing-commits/managing-tags-in-github-desktop
